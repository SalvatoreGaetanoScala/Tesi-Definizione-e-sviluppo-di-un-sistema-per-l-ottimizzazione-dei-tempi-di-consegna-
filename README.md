# Tesi-Definizione-e-sviluppo-di-un-sistema-per-l-ottimizzazione-dei-tempi-di-consegna-
La tesi affronta le problematiche legate alla logistica della Last Mile Delivery (conse gna dell’ultimo miglio), con l’obiettivo primario di migliorare globalmente il tempo di viaggio e l’efficienza delle spedizioni.

L'obiettivo è calcolare il "tempo di servizio" (tempo associato alla consegna del prodotto da parte del corriere) tramite un dispositivo basato su ESP32. 
Vi sono 2 tipologie di script di codice:
- quelli racchiusi nella cartella src che gestiscono la logica del sistema embedded (ESP32 simulato in locale in WOKWI);
- quelli inseriti in SCRIPT_PYTHON che simulano una mappa generata randomicamente;
